# Product

## Register

product

## Users

NIO Radio listeners using a phone browser, often one-handed and while moving between other tasks. They want to find the newest programs, start or resume playback quickly, and inspect the current queue without leaving the page.

## Product Purpose

Provide a dependable mobile web player for the public NIO Radio catalog. Success means the latest programs load without a request storm, playback and queue state survive a refresh on the same device, failures are recoverable, and the installed PWA opens correctly from GitHub Pages.

## Brand Personality

Calm, direct, and familiar. The interface should feel like a focused native media utility: confident but quiet, with concise Chinese labels and no explanatory marketing copy.

## Anti-references

- Do not resemble a vehicle dashboard or large-format in-car interface.
- Do not use a decorative marketing landing page, card-heavy dashboard, or dark neon media-player aesthetic.
- Do not hide standard playback and navigation behaviors behind unfamiliar gestures or symbols.

## Design Principles

- Put the current listening task within one thumb reach.
- Preserve context: overlays close back to the exact page and playback never stops just because navigation changes.
- Make freshness and failure honest; cached data is labeled and network errors always provide a next action.
- Prefer familiar mobile media patterns over novelty.
- Keep the full catalog available without transferring discovery cost to every visitor.

## Accessibility & Inclusion

Meet WCAG 2.1 AA for contrast and semantics. Support 320–430px widths, 200% text zoom, keyboard navigation, screen-reader labels, safe areas, focus containment/restoration, and reduced motion. Interactive targets are at least 44px.
