# NIO Radio 社交宣传物料设计

## Goal

为 B 站和小红书各准备一套可直接上传的图文物料。不做独立落地页。视觉沿用 App 青绿与实机截图。

## Audience

封面两边都能看懂。第 2 张偏蔚来车主（今日更新），第 3 张偏普通听众（进度 / 稍后播放）。其余页两边共用。

## Deliverables

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `docs/promo/xiaohongshu-01.png` … `06.png` | 1080×1440 | 小红书笔记图，按序号发布 |
| `docs/promo/bilibili-cover.png` | 1920×1080 | B 站封面，构图来自第 1 张 |
| `docs/promo/copy.md` | — | 两套可粘贴文案 |

## Six frames

1. 封面：「蔚来播客，打开就能听」+ 图标 + 今日推荐首页一角
2. 车主向：首页实机 + 「每天自动更新」
3. 听众向：播放器 / 队列 + 「进度留在自己设备上」
4. 白噪音：专辑页 + 「雨声风声」
5. 电脑版：桌面侧栏 + 「手机和电脑是同一个」
6. 怎么用：`https://nio.k4le.top/` + 安卓「添加到主屏幕」/ iPhone「分享 → 添加到主屏幕」。图上不放二维码。

## Visual system

- 颜色：青绿 `#00BEBE`，字 `#08162E`，底 `#FFFFFF`
- 版式：上约 1/3 一句主张，下约 2/3 实机；左上角小图标；四周留白；字不压在封面上
- 截图来源：线上 `https://nio.k4le.top/` 当前界面，去掉浏览器框
- 手机帧宽度按 390；电脑帧用桌面布局
- 无渐变字、无贴纸风

小红书标题：蔚来播客网页版，打开就能听

小红书正文：

```
给官方播客做了个网页播放器，手机电脑都能用，不用装商店里的 App。

今天更新什么，打开就能看到。
听到一半关掉，进度还在自己设备上。
想留着的丢进稍后播放。
白噪音也能垫着通勤或书桌。

安卓：浏览器菜单 → 添加到主屏幕
iPhone：分享 → 添加到主屏幕

https://nio.k4le.top/

#蔚来 #NIO #播客 #车机 #白噪音
```

B 站标题：蔚来播客，打开就能听｜NIO Radio 网页播放器

B 站简介：

```
手机和电脑都能用的 NIO 播客播放器。每日更新目录，进度和稍后播放存在本地，可以加到主屏幕。

打开：https://nio.k4le.top/
安卓在浏览器里安装；iPhone 用分享添加到主屏幕。
```

B 站标签：蔚来、NIO、播客、PWA

## Out of scope
