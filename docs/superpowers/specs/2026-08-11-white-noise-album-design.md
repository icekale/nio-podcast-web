# 白噪音自有专辑设计

> 日期：2026-08-11  
> 状态：已确认  
> 范围：Web 端，以 320–430px 移动端为主要验收面

## 目标

在“通勤场景”中增加一张自有专辑“白噪音”，精选 30 条来自 XMSLEEP 的远程环境音。它沿用现有专辑、收藏、播放队列和睡眠定时交互，不增加首页常驻入口，也不改变 NIO 官方专辑的数据请求流程。

成功标准：

- 未收藏时，“白噪音”稳定显示在“通勤场景”最后一位。
- 收藏后，按现有收藏顺序参与置顶。
- 详情页稳定展示 30 条声音，雨声排在最前。
- 播放任一声音时循环当前声音；用户仍可手动上一首或下一首。
- 沿用现有 15 / 30 / 45 / 60 分钟睡眠定时；循环声音不显示“本集结束”。
- 浅色和深色模式自动使用对应封面，不增加主题设置。

## 内容与文案

- 专辑名：`白噪音`
- 分类：`commute`（通勤场景）
- 专辑简介：`让雨声与风声，陪你安静抵达。`
- 集数：30
- 内部保留一个不与 NIO 现有编号冲突的数值型专辑 ID；路由继续使用现有 `/album/:id` 形式。

专辑页面不展示音频来源文案。必要的许可证和来源说明写入仓库第三方许可文件，不占用播放界面。

## 数据架构

新增一个小型自有专辑模块，集中导出：

- 专辑元数据，包括分类、简介、封面和第一条声音摘要。
- 30 条标准化节目对象，包括稳定 ID、标题、时长、远程音频 URL 和 `loop-one` 播放标记。
- 判断自有专辑和循环声音的纯函数。

目录加载完成并标准化 NIO 数据后，在客户端注入自有专辑。`getEpisodes()` 识别自有专辑 ID 后直接返回本地清单；其他专辑仍走现有 NIO API、缓存、超时和错误处理。目录生成脚本不扫描、不更新也不写入自有专辑，因此定时目录刷新不会覆盖它。

自有专辑是常青内容，不进入“今日更新 / 最新更新”的节目流；它仍可出现在全部专辑、分类目录、搜索、收藏和稍后播放的专辑选择器中。

远程音频使用 XMSLEEP GitHub 仓库的固定提交地址，而不是会变化的 `main` 地址。这样仍是直接引用源项目，不增加本站音频体积，同时避免上游改名或移动文件导致链接无预警变化。音频格式保持 OGG/Vorbis；用户已接受其移动端兼容范围。

## 排序规则

沿用现有目录排序层级：收藏优先于置顶和普通内容。自有专辑增加一个“默认末尾”层级：

1. 收藏专辑，按现有收藏顺序。
2. 现有置顶与提升权重专辑。
3. 其他普通专辑，按现有规则。
4. 未收藏的“白噪音”。

该规则只影响目录排序，不改变搜索匹配和收藏存储格式。

收藏入口统一沿用现有 Lucide `Heart`：未收藏为空心，收藏后为实心。不得为“白噪音”使用五角星或新增第二套收藏语义。

## 播放与睡眠定时

自有声音使用现有播放队列和迷你播放器。每条声音带 `playbackMode: 'loop-one'`：

- `<audio>` 对当前声音启用循环，播放结束不自动前进。
- 上一首、下一首和从队列点选仍正常工作。
- 普通播客继续在结束时自动播放下一条，行为不变。
- 睡眠定时到期时暂停音频并清除定时状态，即使当前声音正在循环。
- 循环声音打开睡眠定时菜单时，仅显示 15 / 30 / 45 / 60 分钟和关闭定时，不显示“本集结束”。
- 若用户从带有“本集结束”定时的普通播客切换到循环声音，清除该不再可兑现的定时状态。

远程音频失败时复用现有播放器错误提示和“重试”，不新增弹窗或专属错误页面。

## 封面与主题

视觉方向为用户确认的“水纹”：抽象同心水纹、低信息密度、无照片和装饰性插画。构图在小尺寸缩略图中保持清晰，标题位置固定，字距为 0。

- 浅色封面：浅青 `#E7F7F7` 背景、青绿 `#00B9B5` 水纹、深墨 `#08162E` 文字。
- 深色封面：深墨 `#08162E` 背景、亮青 `#2BD0C6` 水纹、雾白 `#F0F6FA` 文字。
- 两个版本使用完全相同的水纹、字号和字标位置，只替换主题色。
- 封面不显示“白噪音”标题，也不保留左上角的小型 `NIO RADIO` 文字；底部居中仅保留一枚横排 `NIO Radio` 字标，参照现有 NIO Radio 专辑封面的粗细组合：`NIO` 粗体、`Radio` 细体。
- 正式资产输出为方形 PNG，至少 1200×1200；应用通过 `prefers-color-scheme` 自动选择对应版本。

现有专辑卡片、详情页、节目行、队列和迷你播放器继续使用同一 `Artwork` 组件。组件增加可选深色资源能力；未提供深色图的所有现有专辑保持原样。

## 无障碍与响应式

- 保持现有 44px 最小触达区域、键盘焦点、列表语义和按钮标签。
- 封面标题属于图像内容；专辑名仍以真实文本显示，封面使用空替代文本以避免重复朗读。
- 在 320、390、430px 宽度验证标题、简介、30 条列表、菜单和迷你播放器无溢出或遮挡。
- 深浅主题分别检查封面辨识度；不新增动画，现有 reduced-motion 行为不变。

## 测试与验收

- 自有专辑注入一次，不因缓存目录重复加载而重复。
- 自有专辑未收藏时在通勤分类末尾，收藏后进入收藏置顶区。
- 搜索“白噪音”可找到专辑；首页更新流不出现该常青专辑。
- `getEpisodes()` 对自有 ID 返回 30 条且不发起 NIO API 请求；普通 ID 行为不变。
- 雨声顺序、稳定 ID、远程 URL 和时长结构正确。
- 循环声音结束不前进；普通节目仍自动前进。
- 循环声音隐藏“本集结束”；15 / 30 / 45 / 60 分钟到期仍暂停。
- 浅色和深色封面在目录、详情、节目行、队列和迷你播放器中正确切换。
- 运行 Vitest、lint、生产构建和现有 Playwright E2E。
- 使用浏览器在 320×700、390×844、430×932 以及桌面宽度进行截图与控制台检查。

## 非目标

- 不复制、转码或缓存 XMSLEEP 音频到本站。
- 不加入混音、多声道同时播放、单独音量、番茄钟或自定义倒计时时长。
- 不增加新的播放器、专辑布局、首页模块或设置页。
- 不更改现有普通播客的播放结束、队列和睡眠定时行为。
