# NIO Radio 专辑主题分类优化设计

**日期：** 2026-08-28

**目标：** 将 Web/PWA 的专辑目录从低覆盖率的驾驶场景分类改为 7 个稳定主题分类，使当前目录中未分类专辑比例从 67.3% 降至 10% 以下，同时保留现有搜索、收藏、排序、队列和播放行为。

## 现状

当前目录共有 568 个专辑，其中 382 个（67.3%）没有分类，只能进入「更多专辑」。现有 6 个驾驶场景规模差异明显：「通勤场景」和「玩转爱车」各 7 个，「城市漫游」95 个。分类主要依赖少量人工专辑 ID 和专辑名称关键词，宽泛词还会造成误分，例如仅凭「故事」会把成人内容归入儿童分类。

官方 API 没有可直接使用的分类字段，因此继续在 catalog 生成阶段完成分类，浏览器只消费生成后的 `category`。

## 分类结构

每个专辑只归入一个一级主题，页面顺序固定为：

1. `news`：资讯热点
2. `car`：汽车蔚来
3. `business`：商业科技
4. `culture`：文化知识
5. `lifestyle`：生活兴趣
6. `audio`：音乐声音
7. `kids`：亲子成长

分类边界如下：

- **资讯热点**：新闻、早晚报、城市资讯、时事观察、赛事速递。
- **汽车蔚来**：车型、用车、驾驶、赛车、蔚来品牌和车主社区内容。
- **商业科技**：商业、财经、创业、职场、科技、互联网和 AI。
- **文化知识**：历史、人文、读书、艺术、科普和知识型访谈。
- **生活兴趣**：旅行、美食、健康、体育、游戏、影视、时尚和泛生活谈话。
- **音乐声音**：音乐节目、点歌、演出、声音作品和白噪音。
- **亲子成长**：明确面向儿童、家长或家庭教育的内容。

无法可靠判断的专辑保持 `category: null`，进入末尾的「更多专辑」。它是安全兜底，不是第 8 个正式主题。

## 分类生成

分类逻辑保留在 `scripts/album-categories.js`，并由 catalog 生成流程调用。判断文本由专辑名、专辑简介和最新一期标题组成，统一大小写及空白后再匹配。

命中顺序为：

1. 人工专辑 ID 映射。
2. 自动主题规则。
3. `null` 兜底。

自动规则冲突时按以下优先级选择唯一类别：

`汽车蔚来 → 亲子成长 → 音乐声音 → 资讯热点 → 商业科技 → 文化知识 → 生活兴趣`

规则只使用能够明确表达主题的词组。`故事`、`成长`、`声音`等宽泛单词不能单独决定类别；已有的明确人工映射继续优先，用于处理标题含义不直接或历史上容易误分的专辑。

每次目录生成在控制台输出各分类数量、未分类数量，以及未分类专辑的 ID 和名称。未分类比例超过 12% 时输出醒目告警，但不让目录生成失败；分类原因和置信度不写入线上 `albums.json`，避免增加客户端不使用的数据。

## 页面呈现

`src/catalog.js` 和 `CategorySections` 使用新的主题 ID、短名称和固定顺序。分类标题直接显示主题名和专辑数量，不再显示 `场景|子类` 双标签。

以下行为保持不变：

- 每类默认展示前 12 个专辑，可展开全部。
- 收藏专辑在所属分类内优先显示。
- 现有置顶、加权和更新时间排序继续生效。
- 搜索框为空时显示分类目录；输入关键词后直接显示匹配结果。
- 只有存在未分类专辑时才显示「更多专辑」。

自建白噪音专辑归入「音乐声音」。不支持 OGG 的设备仍按现有逻辑隐藏它。

## 缓存与兼容

重新生成 `public/data/albums.json` 时直接替换现有 `category` 值，不更改专辑 ID、节目 ID 或目录结构。收藏、播放队列、播放进度和分享路由均不依赖分类 ID，因此不需要迁移。

现有本地目录缓存最多继续使用 5 分钟，随后由新目录自然替换。不修改缓存 key，也不增加分类版本或客户端重分类逻辑。新增专辑或信息不足的专辑进入「更多专辑」，不会阻止目录发布。

## 测试与验收

测试覆盖：

- 7 类典型专辑的自动归类。
- 人工 ID 映射优先于自动规则。
- 多类命中时的固定优先级。
- `故事`、`成长`、`声音`等宽泛词不单独触发误分。
- 无法判断时返回 `null`。
- 新主题顺序、显示名称、分组和分类内现有排序。
- 白噪音归入「音乐声音」。
- 生成报告正确统计分类覆盖率，并在未分类比例超过 12% 时告警但不抛错。

首次发布验收要求当前完整目录未分类比例低于 10%。后续目录更新允许陌生专辑进入「更多专辑」，避免分类维护阻断节目更新；12% 告警用于提示集中补充规则或人工映射。

验收时重新生成 catalog，检查分类数量和未分类清单，对每个主题抽查最新、最旧及边界专辑。运行完整单元测试、lint 和 PWA build。页面上确认全部专辑页与空搜索页使用新顺序，展开、收藏和专辑播放行为不变。

## 范围

本次只调整 Web/PWA 的专辑主题分类、catalog 生成规则、分类目录文案和相应测试。不要修改首页日间播放列表、专辑详情分页、播放器状态模型、队列、收藏持久化、搜索匹配方式、PWA 缓存策略或小程序。
